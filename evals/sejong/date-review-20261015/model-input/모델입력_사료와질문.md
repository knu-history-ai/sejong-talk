# 모델 입력 자료와 질문

사료와 질문만 담았습니다. 원문 링크는 출처 확인용이며 실험 중 링크를 열어 내용을 추가하지 않습니다. […]는 발췌문 중간 생략 표시입니다. 주석 번호·웹 링크 표시는 제외했고, 인명·지명 링크 경계의 불필요한 공백은 정리했습니다.

공통 지시: 자료만 근거로 연·월과 확인 가능한 일자를 답하고 근거 구절도 제시해 주세요. 정확한 일자를 확인할 수 없으면 확인할 수 없는 범위를 밝혀 주세요.
