# 정답표 초안 · 모델에 제공하지 마세요

작성 2026-10-14 / 검수 요청일 2026-10-15 / 사람 검수 미완료(draft). 이 문서는 모델 답변이 아니라 공식 웹 국역을 확인해 작성한 정답 초안입니다. 원본 이미지 전수 대조는 아직 하지 않았습니다.

## 공통 채점 기준

모든 대상의 확인 가능한 연·월·일이 맞아야 1점. 이번 질문은 공통 지시에서 연도를 요구하므로 연도도 필수다. 본문에 없는 일자를 만들거나 특정 일을 근거 없이 부정하면 0점. 일자가 없으면 연·월과 일자 확인 불가를 함께 답한다. 표제 날짜 언급 자체는 오류가 아니다. 월 초·말 추정과 양력 환산은 허용하지 않는다. 당일 행위를 적은 기록과 과거 사건을 회고한 본문을 구분한다.

모든 대상 사건에 대해 자료 안의 인용 또는 허용된 바꿔 쓰기가 실제 답변을 뒷받침해야 1점. 인용 존재 여부만으로 의미상 지지를 판정하지 않음. 날짜 1점이라도 근거가 틀리거나 없으면 근거 0점.

일자 확인 불가는 day에만 적용한다. 이번 자료에서 확인 가능한 연·월까지 모른다고 답하면 날짜 0점이다.

이번 질문은 공통 지시로 연도를 요구하므로 정답 JSON의 required에 year를 포함합니다. 예비시험의 연도 생략 허용을 이번 문항에 그대로 적용하지 않습니다. 같은 문항을 세 방식 모두에 동일하게 적용합니다.

단일 문항의 모든 대상이 맞아야 날짜 1점입니다. 대상별 부분 판정은 별도로 기록하고 문항 전체 점수를 0.5점 등으로 바꾸지 않습니다. 날짜와 근거는 각각 0/1점으로 판정합니다. 인용 위치가 맞아도 실제 주장을 지지하는지는 사람이 확인합니다.

전체 53문항 중 사건 40문항이 core, 표제 대조 13문항은 control입니다. 둘을 합쳐 대표 정답률로 쓰지 않습니다. 같은 기사에서 나온 질문을 독립 기사로 세지 않습니다. 기사 동일 가중 평균도 함께 보고합니다.

호출 실패·시간초과는 부분 답변이 있어도 실행 실패를 우선하고 전체 정답률에서 0점으로 집계합니다. 정상 완료한 모른다는 답이나 읽을 수 있는 형식 오류는 내용을 채점합니다. 미실행·상태 미확인·미채점·미해결 이견은 확정 집계를 막습니다. AI 판정 실패는 모델 실패가 아니며 사람이 원문을 판정합니다. 세부 집계는 #62·PR #70을 적용합니다.
