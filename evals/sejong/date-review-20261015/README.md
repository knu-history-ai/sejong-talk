# 10/15 논문 실험 자료 검수 안내

20기사·53문항의 검수 초안이에요. 시연님의 1차 검수 의견은 [PR #77](https://github.com/knu-history-ai/sejong-talk/pull/77)에 올라왔어요. 민준이 승인한 네 문항의 질문 표현을 v4에 반영했어요. T08은 공유된 개발·실행 기록과 유진·시연님의 답변을 근거로 유지하기로 했으며, 수정 네 문항 재확인과 최종 승인·고정이 남아 있어요. 1차 검수 게시를 정답표 최종 승인으로 처리하지 않아요.

먼저 모델 입력 문서를 공식 원문과 대조하고 정답표를 확인해 주세요. 20기사의 표제·국역 발췌·생략 위치와 53문항의 질문 대상·날짜 정답·근거를 봐주시면 돼요. 날짜는 음력을 유지하며 기사 날짜와 사건 날짜를 구분해요. 본문에 없는 일자를 단정하거나 알려진 날짜를 빠뜨리지 않았는지도 확인해 주세요.

수정·보류 항목은 검수 기록에 문항 ID와 원문 위치·이유를 적어주세요. 국역만으로 판단하기 어려우면 보류로 남겨주시면 돼요. 새 사료 수집·한문 번역·앱 연결·평가도구 수정·모델 답변 채점은 #71 자료 검수에 포함하지 않아요. 실험 후 답변의 독립 검증은 별도 #76에서 관리해요.

## 현재 분담과 실행 규모

- 시연: #71의 전체 20기사·53문항 자료 검수. 실험 후 #76의 표본 답변 검증도 추가 요청한 상태이며, 자료 검수 수락과 별개로 추가 검증 수락은 아직 미확인이에요.
- 선영: #76에서 시연님과 같은 완료 표본을 독립 검증해요. 10/15 수락했고 10/16 중 진행한다고 했으며 정확한 완료 시각은 미확정이에요. #71 자료 검수를 새로 맡기는 것은 아니에요.
- 민준: 검수 수정 반영·자료/정답표 고정 확인, 익명 자료·빈 양식·작성 예시 준비/배포, 수합·이견 정리 진행·분석·논문 작성을 맡아요. 두 사람의 독립 첫 판정에는 참여하지 않아요.
- 도구 담당: PR #70의 코드·테스트·실행 폴더 준비·자동 평가·판정 파일 등록·집계를 맡아요.
- 유진: 준비된 명령 실행·기록·전체 폴더/오류 전달만 맡아요. 설정·검수·내용 채점·집계는 맡지 않아요. 정민님에게 독립 검증을 중복 배정하지 않아요.

전체 계획은 **53문항×R/P/E/T/V 5방법×1회 = 265개 예정 출력**이에요. R은 규칙, P는 강화 프롬프트, E는 근거 우선, T는 표시 대조, V는 근거·정밀도 검사예요. T/V는 같은 P 원본을 공유하므로 정상 생성 호출은 P 53회+E 106회, 총 **159회이며 준비 호출 1회는 별도**예요. 출력 수·모델 호출 수·평가 비용을 구분하고 실제 실패·중단은 원본대로 기록해요.

전체 구조화 날짜는 코드로 자동 평가하고 AI 의미·근거와 사람 표본은 보조 결과로 분리해요. 승인 자료로 실행 전에 seed 62, `type-balanced-twelve-v2`를 사용해 날짜 5유형을 균형 있게 고른 **12문항×5방법 = 60개 예정 표본 출력**을 고정해요. 시연·선영이 같은 완료 표본을 각각 최대 60개씩 독립 검증하며 절반씩 나누지 않아요. 확정 생성 실패는 고정 분모에 0점으로 남기되 없는 답변을 사람이 채점하지 않아요. 아직 실제 본실험 표본을 고정하거나 검증 자료를 전달한 상태는 아니에요.

두 사람의 첫 판정이 각각 저장·고정될 때까지 방법·자동 점수·상대 판정·대응표를 가려요. 민준은 준비에 필요한 대응표를 관리하되 판정을 유도하거나 대신 작성하지 않아요. 이견은 원문·정답표로 정리하고 첫 파일을 보존해요. 미해결이면 별도 수락을 받은 제3 검토자가 필요하며 민준·정민·유진에게 자동 배정하지 않아요. 사람 미제출·보류·미해결은 표본 완료 보고만 막고 전체 자동 계산과 분리해요. 표본을 전체 사람 정답률로 확대하지 않아요. 세부 기준과 목표 일정은 [#62](https://github.com/knu-history-ai/sejong-talk/issues/62)·[#76](https://github.com/knu-history-ai/sejong-talk/issues/76)을 따라요.

## 자료와 정답 분리

모델 입력은 `model-input`, 검수자용 정답표와 검수 기록은 `reviewer-only`에 있어요. 정답표와 이 안내를 답변 생성 모델에 넣지 않아요. `dataset.json`은 평가도구용이고 집계용 사건 묶음 정보도 포함해요. 파일 전체를 모델에 붙여 넣지 마세요. 수동 입력에는 모델 입력 문서를 사용해요.

자료는 `date-review-20261015-20articles-draft-v4`예요. T16-Q01과 T15·T17·T18의 Q01이 기사 기록 날짜가 아니라 본문의 사건 시기를 묻도록 표현을 명확히 했어요. 날짜 정밀도 요구·정답·근거·채점 기준은 그대로예요. v3의 T12 월 힌트 ID 제거와 T07-Q01·T13-Q01·T14-Q01 근거 보강도 유지했어요. 사건 질문 40개·표제 날짜 대조 13개, 대상별 정답 58개이며 최종 확정본은 아니에요. [반영 내역과 개발 사용 이력 확인](reviewer-only/검수의견_반영내역.md)을 함께 봐주세요.

## 검수 후 순서

민준이 검수 의견을 반영하고 원문·질문·정답을 다시 확인해요. 해결되지 않은 항목은 확정 정답으로 쓰지 않아요. 관련 사건의 개발용/최종 평가용 중복도 확인한 뒤 실제 검수자 기록과 승인 상태·버전·해시·기준을 고정하고 #62에 결과를 남겨요. 도구 담당이 PR #70의 최신 준비기로 표본을 실행 전에 고정하고 정답표 없는 별도 실행 폴더를 만들어요. 유진님은 전달 폴더에서 `node "./run-evaluation.mjs"`만 실행하고 기록·전체 폴더/오류를 돌려줘요. 결과를 받은 뒤 민준·도구 담당이 익명 검증 자료·빈 양식·작성 예시를 시연·선영에게 각각 전달해요.

기존 #57의 S1~S3 자료·앱 연결과 별도이고 #56의 기본 앱 시험을 기다리게 하지 않아요. 앱에 자료를 다시 등록하는 작업이 아니며 PR #70의 예비시험 명령도 이 20기사 자료를 자동으로 실행하지 않아요. 이 PR은 자료 공유용으로 평가 코드를 포함하지 않아요. 현재 명령·유형별 집계·자동/표본 결과 구분은 [PR #70 실행 안내](https://github.com/knu-history-ai/sejong-talk/blob/codex/date-eval-62/docs/date-automatic-sample.md)를 따라요.

공식 링크는 출처·검수용이에요. 실험에서는 제공한 발췌문만 사용하고 링크를 열어 자료를 추가하지 않아요. 최종 후보로 실제 모델 답변을 보거나 프롬프트를 조정했다면 해당 사건 묶음을 개발용으로 옮겨요. 이 묶음만으로 실록 전체나 한국어 인식률을 주장하지 않아요. 국역 출처·이용 조건은 정답표에 적었어요.
