# 10/15 논문 실험 자료 검수 안내

20기사·53문항의 검수 초안이에요. 초안은 민준이 준비했고 시연님께 공식 국역과 발췌문·질문·정답표 대조를 부탁드리려고 해요. 10/15 검수 가능 여부와 일정은 아직 확정하지 않았어요.

먼저 모델 입력 문서를 공식 원문과 대조하고 정답표를 확인해 주세요. 20기사의 표제·국역 발췌·생략 위치와 53문항의 질문 대상·날짜 정답·근거를 봐주시면 돼요. 날짜는 음력을 유지하며 기사 날짜와 사건 날짜를 구분해요. 본문에 없는 일자를 단정하거나 알려진 날짜를 빠뜨리지 않았는지도 확인해 주세요.

수정·보류 항목은 검수 기록에 문항 ID와 원문 위치·이유를 적어주세요. 국역만으로 판단하기 어려우면 보류로 남겨주시면 돼요. 새 사료 수집·한문 번역·앱 연결·평가도구 수정·모델 답변 채점은 이번 요청에 포함하지 않아요. 독립 채점은 실제 답변이 나온 뒤 별도로 협의해요.

## 자료와 정답 분리

모델 입력은 `model-input`, 검수자용 정답표와 검수 기록은 `reviewer-only`에 있어요. 정답표와 이 안내를 답변 생성 모델에 넣지 않아요. `dataset.json`은 평가도구용이고 집계용 사건 묶음 정보도 포함해요. 파일 전체를 모델에 붙여 넣지 마세요. 수동 입력에는 모델 입력 문서를 사용해요.

자료는 `date-review-20261015-20articles-draft-v3`예요. T12의 월 힌트 ID를 제거하고 T07-Q01·T13-Q01·T14-Q01의 근거 인용을 보강했어요. 날짜 정답·질문은 유지했어요. 사건 질문 40개·표제 날짜 대조 13개, 대상별 정답 58개이며 최종 확정본은 아니에요.

## 검수 후 순서

민준이 검수 의견을 반영하고 원문·질문·정답을 다시 확인해요. 해결되지 않은 항목은 확정 정답으로 쓰지 않아요. 관련 사건의 개발용/최종 평가용 중복도 확인한 뒤 버전·해시·기준을 고정하고 #62에 결과를 남겨요. 그 후 담당자가 새 자료용 실행 설정을 준비해요. 유진님은 준비된 명령 실행·기록과 결과 폴더 전달만 맡아요.

기존 #57의 S1~S3 자료·앱 연결과 별도이고 #56의 기본 앱 시험을 기다리게 하지 않아요. PR #70의 예비시험 명령은 이 20기사 자료를 자동으로 실행하지 않아요. 이 PR은 자료 공유용이며 유형별 집계 코드 보완은 포함하지 않아요.

공식 링크는 출처·검수용이에요. 실험에서는 제공한 발췌문만 사용하고 링크를 열어 자료를 추가하지 않아요. 최종 후보로 실제 모델 답변을 보거나 프롬프트를 조정했다면 해당 사건 묶음을 개발용으로 옮겨요. 이 묶음만으로 실록 전체나 한국어 인식률을 주장하지 않아요. 국역 출처·이용 조건은 정답표에 적었어요.
