## 공통 기록과 판정 범위

- 입력 버전: `date-pilot-v1` / 정답 버전: `date-pilot-answer-v2`.
- 초안 작성·공식 국역/한문 시간 구절 대조: Codex(AI), 2026-10-12(KST).
- 시연의 원문 대조 1차 확인: 완료(2026-10-12, 이 채팅에서 사료·정답표 확인). 민준 최종 확인·승인: 미완료. 독립 교차 검토: 미실시.
- 모든 문항 상태: 탐색용·판정 보류. 아래는 승인 전 검토 기준이며 확정 채점에 쓰지 않는다.
- 사건 연도는 공식 표제에서, 사건 월·일은 해당 본문에서 해석한다. 왕년 또는 대응 연도 표현을 허용한다. 날짜는 실록 음력이며 양력 변환값은 정답으로 쓰지 않는다.
- 연·월까지 확인되는 문항은 그 범위를 제시해야 한다. 일자가 확인되는 문항은 월·일까지 답해야 한다. 문맥상 같은 해가 명확하면 연도의 반복 생략을 허용한다.
- 근거 없는 정확한 날, 사건 혼동, 필요한 날짜를 전부 모른다고 하는 답변은 실패 후보다. 표제 날짜를 별도로 인용하면서 사건의 날은 불명이라고 구분하는 답변은 허용한다.
- 3개 기사에서 만든 8개 문항이다. 독립 사료 8건으로 세지 않는다. 실제 자료 입력 증거가 없으면 날짜 오답률에 합산하지 않는다.
