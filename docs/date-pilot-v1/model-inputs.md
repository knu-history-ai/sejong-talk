# 날짜 해석 예비시험 — 모델 입력 자료 v1

관련 작업: [#57](https://github.com/knu-history-ai/sejong-talk/issues/57), 질문 기준: [#56](https://github.com/knu-history-ai/sejong-talk/issues/56).

자료 버전: `date-pilot-v1` / 공통 지시 버전: `issue56-B-v1` / 확인일: 2026-10-12(KST).
작성·공식 본문 대조: Codex(AI). 시연 1차 확인: 완료(2026-10-12, 이 채팅에서 확인). 민준 최종 확인·승인: 미완료.
상태: 시연 1차 확인 완료 / 탐색용 / 판정 보류. 팀 공유와 민준 최종 승인 대기.

## 사용 순서

1. 아래 공통 지시, 해당 사료의 `text` 블록, 해당 질문을 순서대로 합쳐 한 번에 입력한다. 문서 전체를 붙이지 않는다.
2. Ollama의 별도 MODEL 경로에서 문항마다 새 대화로 실행한다. B02도 B01 답변 없이 독립 실행한다.
3. 정답표와 검토 기록은 모델에 넣지 않는다. URL만 주는 대신 아래 발췌 본문을 반드시 넣는다.
4. 실제로 보낸 전체 입력, 자료 버전과 검토 상태, 실제 답변 원문, 모델·설정은 #56 양식으로 기록한다. 최종 승인 전 내용 판정은 보류한다.

공통 지시(아래 블록 복사 후 해당 사료 블록과 `[질문]`을 이어 붙인다):

```text
아래 세종실록 국역 자료만 근거로 질문에 답해 주세요. 기사 표제 날짜와 본문이 말하는 사건 시점을 구분하고, 근거에서 확인되는 범위까지만 답해 주세요. 날짜가 명시되어 있다면 생략하지 마세요. 음력 날짜를 양력으로 바꾸지 마세요.
```
