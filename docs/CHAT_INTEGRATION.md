# W03-11 글 대화 연결 (#46)

기본 화면은 세션 생성 API와 `POST /api/turns`를 호출한다. 승인 응답의 답변·출처를 표시하며, 질문 재시도는 새 requestId를 사용한다. 실패를 샘플 답변으로 대체하지 않는다. 개발 환경의 `?sample=1`에서만 샘플 화면을 사용한다.

서버는 쿠키·Origin으로 세션을 인증하고, 클라이언트의 최근 대화나 sessionId를 받지 않는다. 최근 승인 대화는 세션 저장소에서 읽는다. 같은 ID·같은 질문은 이전 결과를 반환하고, 다른 질문은 409로 거절한다. 요청 조회·취소는 `GET/DELETE /api/requests/{id}`로 해당 세션 내에서만 가능하다. 세션 초기화·만료 이후의 결과는 저장하지 않는다.

## 미완료 연결

현재 브랜치에는 사용량 보호 PR #45가 없다. `src/server/ai/http.ts`의 기본 생성 함수는 외부 호출 없이 503/UNAVAILABLE을 반환한다. 따라서 실제 AI 답변 통합은 완료 상태가 아니다.

#45 병합 후 기본 생성 함수를 인증된 sessionId를 받는 실제 AI 진입점으로 연결해야 한다. 사용량 원장·공급자 무료 계획 검사·세션별 한도를 반드시 함께 적용한다. 기존 RequestCoordinator와 중복 조정이 생기지 않도록 호출 범위를 검토한다. `USAGE_PROVIDER_PLANS`에 콘솔에서 확인된 무료 공급자를 등록하고 GEMINI_API_KEY를 서버 환경에 설정한 뒤 실제 응답을 확인한다. 키는 브라우저나 저장소에 넣지 않는다.

실제 답변의 의미 검증(W03-09), 실제 공급자 호출, 음성 연결은 이번 단계에서 확인하지 않았다.

## 확인 항목

- 기본 화면에서 세션 생성 후 질문 요청 시 명시적인 연결 대기 오류가 나오는지
- 개발 샘플 모드에서 답변·오류·취소·새 대화가 동작하는지
- #45 연결 후 실제 답변 및 출처, 후속 대화, 실패 후 재시도, 취소 후 지연 응답, 세션 만료·초기화·한도 초과 확인
