# 세종톡 질문 초안 20개 — W02-06·W03-06

작성일: 2026-10-10. 상태: 팀 내용 검토 전 초안.

후속 업데이트: 신규 사실 5개를 출처와 함께 facts.json에 pending으로 작성했고, 기존 집현전 상세 출처도 보완했다. 신규 사실은 초안 등록을 완료했고 팀 승인을 기다리고 있다. 현재 준비 상태와 문장별 근거는 [핵심 사실 검토 자료](./SEJONG_FACT_REVIEW.md)를 기준으로 확인한다.

초등학생이 직접 물어볼 법한 질문으로 구성했다. 정답 문장을 외우는 시험이 아니라, 역사적 사실·출처·자료 부족 안내·대화 흐름을 확인하는 질문 목록이다. 현재 승인 사실 카드는 3개이며, 아래의 자료 보강 질문은 사실 카드와 출처를 검토·승인한 뒤 정상 답변 시험에 사용한다. 지금 해당 질문에 자료 부족 안내가 나오는 것은 곧바로 모델 오류를 뜻하지 않는다.

## 핵심 사실 5~8개 준비와 연결

기존 승인 3개에 창제 연도, 반포 연도, 측우기 용도, 해시계 원리, 농사직설 목적의 신규 초안 5개를 더해 핵심 사실 8개를 준비했다. 신규 5개는 팀 검토 전 pending이다. D11의 농업 관계는 신규 측우기 카드에 포함했다.

질문 20개가 모두 별도의 사실 카드 20개를 요구하는 것은 아니다. 같은 사실을 다른 표현으로 묻거나 잘못된 전제를 넣어 답변 일관성을 확인한다. 이후 자료를 20~30개로 확대할 때 과학·농업·인물·생활 주제의 질문도 추가한다.

## 실제 시험 기록 방법

모델·양자화·자료 버전·시험 날짜를 기록한다. 각 질문별 실제 답변과 표시된 출처를 남기고 다음 항목을 각각 평가한다.

1. 질문 의도에 맞는 답변인가?
2. 확인된 자료와 사실이 일치하는가?
3. 출처 링크가 열리고, 해당 출처가 답변의 주장을 뒷받침하는가?
4. 자료가 없거나 승인되지 않았을 때 꾸며내지 않는가?
5. 초등학생이 이해하기 쉬운 말로 설명하는가?

이어 묻기는 새 세션을 만들지 않고 순서대로 수행한다. 자료 선택 실패, 모델 답변 오류, 출처 표시 오류를 구분해서 담당자에게 전달한다. 신규 사실은 서비스 자료에 pending으로 작성했으며 고정 평가 JSON과 PR #51은 변경하지 않았다. 팀 검토 후 별도 자료 작업 이슈·브랜치에서 승인과 평가 반영을 진행한다.
