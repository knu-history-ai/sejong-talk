## 검토 시 주의할 범위

- 반포 연도는 교과서의 1446년 설명을 사용한다. 국립국어원 글은 정확한 반포 월·날짜와 공식 반포 행사의 기록을 구분하므로 특정 날짜나 행사 장면은 추가하지 않았다.
- 측우기·앙부일구를 세종 또는 장영실이 혼자 발명했다고 단정하지 않았다. 앙부일구 자료는 제작 참여자에 관해 추정과 기록을 구분한다.
- 측우기 사진의 영조 때 유물과 현존 앙부일구의 조선 후기 유물을 세종 때 원본으로 설명하지 않는다.
- 기존 집현전 source ID는 참조 호환을 위해 유지했지만 실제 기관·제목·URL은 한국학중앙연구원 자료로 변경했다.
- facts.json의 전체 항목은 15개다. 이 문서의 핵심 사실 8개 외에 최신 dev의 날짜 pending 카드 5개와 기존 감정 pending·현대 경험 rejected 시험 항목 2개를 유지했다. 승인 3개·pending 11개·rejected 1개다. 출처는 총 11개이며 날짜 출처 3개도 보존했다.
- 새 카드 5개를 승인한 뒤 D08~D13을 정상 답변 시험으로 사용한다. 그전에는 자료 부족 안내가 나올 수 있다.

팀 검토자는 문장별 사실 범위·출처 근거·초등학생 표현을 확인하고 승인 여부를 결정한다. 이슈 #7의 별도 자료 Draft PR로 공유하며 화면 통합 PR #51과 분리한다.
