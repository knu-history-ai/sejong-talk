## 앱 연결 확인

- `data/characters/sejong/facts.json`에 S1~S3 관련 사실 카드 5개를 추가했다.
- `data/characters/sejong/sources.json`에 조선왕조실록 상세 출처 3개를 추가했다.
- 신규 사실은 모두 `pending`이다. 팀 검토 전에는 앱 답변 근거로 선택되지 않는다.
- 현재 자료 선택 함수 `selectReviewedFactsForQuestion`는 `reviewStatus === "approved"` 조건을 사용한다.
- `tests/ai-backend.test.mjs`에서 pending 날짜 사료가 프롬프트에 들어가지 않는지, 같은 자료를 승인 상태로 바꾸면 #56식 질문에 선택될 수 있는지 확인한다.
