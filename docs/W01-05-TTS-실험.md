# W01-05 TTS 후보 실험

## 결론과 현재 상태

- 고정 문장 7개, 무료 계층 후보 3개(Azure Speech, ElevenLabs, Typecast), 자동 음성 저장·API 응답 시간 측정 도구를 준비했다.
- 2026-09-26 Azure `ko-KR-InJoonNeural`, ElevenLabs 기본 음성 `Bill`, Typecast `primary`와 `alt` 음성으로 각각 7개 문장을 모두 생성했다. 모든 실행의 실패율은 0%였다.
- 전체 오디오 응답 완료 시간 중앙값은 Azure 700ms, Typecast `alt` 1,169ms, Typecast `primary` 1,173ms, ElevenLabs 1,287ms였다. 두 Typecast 음성의 4ms 차이는 의미가 작으므로 청취 평가로 선택한다.
- Windows 내장 한국어 음성은 `Microsoft Heami` 여성 음성뿐이었다. 동작 확인용 기준선은 될 수 있지만 세종 캐릭터 후보에서는 제외한다.
- Google Cloud 로그인이 막혀 평가 대상에서 제외하고 **Azure F0, ElevenLabs Free, Typecast Free**를 비교한다. Azure F0는 월 50만 자의 Neural TTS 무료 한도를 제공한다. ElevenLabs Free는 월 10,000 credits를 제공하지만 상업적 이용 권한이 없어 비상업 평가와 학교 과제에만 사용한다. Typecast Free는 결제수단 등록 없이 월 15,000 credits를 제공한다.

## 세종 음성의 고증 범위

세종의 실제 음높이, 음색, 발화 속도를 확인할 녹음 자료는 존재하지 않는다. 따라서 이 실험은 “실제 목소리 복원”이라고 표현하지 않고 **역사 기록을 참고한 재현 음성**이라고 표시한다.

국사편찬위원회 조선왕조실록의 세종 졸기는 세종을 인자하면서도 결단력이 있고, 학문을 좋아하며, 간언을 받아들인 인물로 서술한다. 이 기록에서 음향 특성을 직접 추론할 수는 없지만 대화 태도의 근거로는 쓸 수 있다. 이에 따라 평가용 연기 방향은 다음과 같이 고정한다.

- 40대 후반 한국인 남성으로 들리는 목소리
- 지나치게 낮거나 연극적인 “왕 목소리”는 피함
- 차분하고 따뜻하지만 판단을 말할 때는 단호함
- 어린이가 역사 용어를 알아들을 수 있도록 또렷하고 약간 느리게 발화
- 현대 한국어를 기본으로 하고 `하오`, `하시오` 정도만 절제해 사용

서비스에는 다음 문구를 표시한다.

> 역사 기록을 참고해 재현한 AI 음성입니다. 세종대왕의 실제 목소리를 복원한 것이 아닙니다.

## 후보와 기본 설정

| 후보 | 초기 음성/설정 | 확인할 장점 | 주의점 |
|---|---|---|---|
| Azure AI Speech F0 | `ko-KR-InJoonNeural`, 속도 -5%, 음높이 -1st | 월 50만 자 무료, 한국어 남성 Neural 음성, 단순한 REST 호출 | Azure 계정과 Speech F0 리소스 생성 필요 |
| ElevenLabs Free | `eleven_multilingual_v2`, 기본 음성 `Bill` | 성숙하고 균형 잡힌 남성 음색, 자연스러움과 감정 표현 | 월 10,000 credits, Voice Library API 사용 및 상업적 이용 불가 |
| Typecast Free | `ssfm-v30`, 선택한 `voice_id`, Smart Emotion | 한국어 중심 캐릭터 음성, 문맥 기반 감정 표현 | 월 15,000 credits, 대시보드의 실제 한도 확인 필요 |

공급자 기능은 [Azure Speech 가격](https://azure.microsoft.com/pricing/details/cognitive-services/speech-services/), [Azure 한국어 음성 목록](https://learn.microsoft.com/azure/ai-services/speech-service/language-support?tabs=tts), [ElevenLabs 가격](https://elevenlabs.io/pricing), [ElevenLabs 음성 생성 API](https://elevenlabs.io/docs/api-reference/text-to-speech/convert), [Typecast API 가격](https://typecast.ai/pricing/api/), [Typecast TTS API](https://typecast.ai/developers/api)를 기준으로 했다. 역사적 태도 기준은 [세종실록 32년 2월 17일 졸기](https://sillok.history.go.kr/id/kda_13202017_001)를 참고했다.

## Week 1~2 실행안

1. Azure Portal에서 `Speech Services` 리소스를 만들고 가격 책정 계층을 `Free F0`, 지역을 `Korea Central`로 선택한다.
2. `Keys and Endpoint`의 키와 지역을 `.env.local`의 `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`에 넣는다. 키는 문서나 Git에 올리지 않는다.
3. 고정 문장 7개를 합성하고 응답 시간과 실패율을 기록한다.
4. 2명 이상이 발음 정확도, 어린이 명료성, 역사 캐릭터 적합성, 자연스러움을 독립 평가한다.
5. ElevenLabs에서는 무료 계정의 API key와 무료 API에서 허용되는 기본 음성 `Bill`의 `voice_id`를 `.env.local`에 넣어 같은 문장을 비교한다. 무료 계정은 Voice Library 음성을 API에서 사용할 수 없다.
6. Typecast에서는 무료 API key와 선택한 캐릭터의 `voice_id`를 넣고 `ssfm-v30`의 Smart Emotion으로 같은 문장을 비교한다.

## 고정 테스트 문장

원문과 발음 확인 단어는 [`tests/fixtures/tts-w01-05.json`](../tests/fixtures/tts-w01-05.json)에 둔다. 짧은 인사, 초등학생용 설명, 역사 용어, 숫자 표기/전처리, 근거 부족 안내, 긴 답변을 포함한다. 숫자 문장은 `1446`과 `천사백사십육`을 각각 합성해 전처리 필요 여부를 비교한다.

## 실행 방법

1. 사용할 공급자의 값만 `.env.local`에 넣는다. 변수 이름은 [`.env.example`](../.env.example)을 따른다.
2. 아래 중 하나를 실행한다. 스크립트가 `.env.local`을 자동으로 읽는다. 키를 명령 인자나 Git에 넣지 않는다.

```powershell
npm run tts:evaluate -- --provider=azure
npm run tts:evaluate -- --provider=elevenlabs
npm run tts:evaluate -- --provider=typecast --voice=primary
npm run tts:evaluate -- --provider=typecast --voice=alt
```

Typecast 음성을 추가할 때는 첫 음성을 `TYPECAST_VOICE_ID`, 추가 음성을 `TYPECAST_VOICE_ID_ALT`에 넣는다. `--voice=alt`처럼 지정한 이름은 환경 변수 접미사와 결과 하위 폴더 이름으로 사용된다. 예를 들어 `--voice=calm-king`은 `TYPECAST_VOICE_ID_CALM_KING`을 읽고 `typecast/calm-king/`에 저장한다.

한 문장만 재시험하려면 다음처럼 실행한다.

```powershell
npm run tts:evaluate -- --provider=azure --case=historical-terms
```

결과 음성과 `results.json`은 `evals/sejong/w01-05-results/` 아래 공급자별 폴더에 생성되며 Git에는 포함되지 않는다. 같은 공급자를 다시 실행하면 기존 결과를 갱신한다. 기록되는 `apiLatencyMs`는 요청 시작부터 전체 오디오 수신 완료까지다. PRD 목표인 “재생 시작까지” 시간은 W02 재생 UI에서 `play()` 직전과 `playing` 이벤트 사이를 별도로 측정해야 한다.

## 사람 청취 평가표

각 항목을 1점(부적합)~5점(매우 적합)으로 평가한다. 평가자 2명 이상이 서로의 점수를 보기 전에 독립적으로 듣는다.

| 항목 | 판정 질문 | 가중치 |
|---|---|---:|
| 발음 정확도 | 훈민정음·집현전·측우기·앙부일구·자격루와 숫자가 정확한가? | 30% |
| 어린이 명료성 | 초등 3~6학년이 한 번에 알아들을 속도와 발음인가? | 25% |
| 역사 캐릭터 적합성 | 차분함·따뜻함·단호함이 있고 과장된 사극 연기가 아닌가? | 20% |
| 자연스러움 | 문장 연결, 쉼, 억양이 기계적으로 들리지 않는가? | 15% |
| API 응답 시간 | 7개 문장의 중앙값이 3초 안쪽인가? | 10% |

총점은 `발음×0.30 + 명료성×0.25 + 적합성×0.20 + 자연스러움×0.15 + 속도점수×0.10`으로 계산한다. 한 역사 용어라도 반복해서 잘못 읽으면 총점과 관계없이 보류한다.

## 완료 판정

W01-05는 다음 네 조건이 모두 충족되면 완료다.

- 세 후보의 7개 고정 문장 음성 파일이 생성됨
- 공급자별 API 응답 시간 중앙값과 실패율이 기록됨
- 2명 이상이 청취 평가표를 작성함
- 1순위와 예비 후보, 탈락 이유가 이 문서에 기록됨

실제 서비스 적용 단계에서는 승인된 `answerId`의 서버 보관 텍스트만 합성하고, 클라이언트가 보낸 임의 텍스트를 합성하지 않는다. 동일 답변 재청취는 캐시된 오디오를 재사용하며, 새 질문·중지·초기화 뒤 늦게 도착한 음성이 자동 재생되지 않게 한다.
