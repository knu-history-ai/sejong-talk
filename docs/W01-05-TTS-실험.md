# W01-05 TTS 후보 실험

## 결론과 현재 상태

- 현재 서비스 TTS는 **Azure Speech F0, `ko-KR-InJoonNeural`, 속도 -5%, 기본 음높이**로 선택했다. Typecast는 후속 대안 후보이며 현재 서비스 공급자가 아니다. 서버의 공통 합성 경로 뒤에서 공급자를 교체할 수 있도록 유지한다.
- 멘토 방침에 따라 무료 범위에서만 진행한다. 학생 개인 카드나 결제수단을 등록하지 않으며, 유료 계층 전환·결제·유료 사용량 발생을 전제로 실험하지 않는다. 계정 생성이나 기능 사용에 결제가 필요하면 해당 후보 실험을 보류한다. 무료 한도와 리소스 계층은 실제 계정에서 확인한다.
- 고정 문장 7개, 무료 계층 후보 3개(Azure Speech, ElevenLabs, Typecast), 자동 음성 저장·API 응답 시간 측정 도구를 준비했다.
- 2026-09-26 작성자가 Azure `ko-KR-InJoonNeural`, ElevenLabs 기본 음성 `Bill`, Typecast `primary`와 `alt` 음성으로 각각 7개 문장을 생성했고, 모든 실행의 실패율은 0%로 기록했다. 아래 측정값과 1차 청취 의견은 당시의 기록이다.
- 당시 기록된 API 응답 시간 중앙값은 Azure 700ms, Typecast `alt` 1,169ms, Typecast `primary` 1,173ms, ElevenLabs 1,287ms였다. 기존 타이머는 `fetch()` 반환 직후 멈추고 이후 `arrayBuffer()`의 오디오 본문 수신을 제외했다. 따라서 **Azure·ElevenLabs의 수치는 전체 다운로드 완료 시간이 아니며**, 같은 코드로 측정한 Typecast 수치도 수정된 측정과 직접 비교할 수 없다. 원래 수치를 보존하고 새 측정값으로 덮어쓰지 않는다.
- 2026-10-06 스크립트의 측정 종료 지점을 전체 오디오 본문 수신 이후로 옮겼고, Azure 기본 음높이를 서비스 설정과 맞췄다. 수정된 코드로 실제 API 재측정이나 새 청취 평가를 수행하지 않았으므로 새로운 중앙값과 품질 순위는 미확인이다.
- Windows 내장 한국어 음성은 `Microsoft Heami` 여성 음성뿐이었다. 동작 확인용 기준선은 될 수 있지만 세종 캐릭터 후보에서는 제외한다.
- 당시 Google Cloud 로그인이 막혀 평가 대상에서 제외하고 **Azure F0, ElevenLabs Free, Typecast Free**를 비교했다. 조사 당시 무료량은 Azure 월 50만 자 Neural TTS, ElevenLabs 월 10,000 credits, Typecast 월 15,000 credits로 기록했다. ElevenLabs는 비상업 평가·학교 과제에 한정했고 Typecast는 결제수단 등록 없이 평가했다. 이 한도·이용 조건은 당시 기록이며 현재 계정의 권한이나 무료 사용 가능 여부를 보장하지 않는다.

## 세종 음성의 고증 범위

세종의 실제 음높이, 음색, 발화 속도를 확인할 녹음 자료는 존재하지 않는다. 따라서 이 실험은 “실제 목소리 복원”이라고 표현하지 않고 **역사 기록을 참고한 재현 음성**이라고 표시한다.

국사편찬위원회 조선왕조실록의 세종 졸기는 세종을 인자하면서도 결단력이 있고, 학문을 좋아하며, 간언을 받아들인 인물로 서술한다. 이 기록에서 음향 특성을 직접 추론할 수는 없지만 대화 태도의 근거로는 쓸 수 있다. 이에 따라 평가용 연기 방향은 다음과 같이 고정한다.

- 40대 후반 한국인 남성으로 들리는 목소리
- 지나치게 낮거나 연극적인 “왕 목소리”는 피함
- 차분하고 따뜻하지만 판단을 말할 때는 단호함
- 어린이가 역사 용어를 알아들을 수 있도록 또렷하고 약간 느리게 발화
- 현대 한국어를 기본으로 하고 `하오`, `하시오` 정도만 절제해 사용

서비스에는 다음 문구를 표시한다.

> 역사 기록을 참고해 재현한 AI 음성입니다. 세종대왕의 실제 목소리를 복원한 것이 아닙니다.

## Week 1~2 실행안

다음은 초기 실행안을 현재 선택과 무료 전용 방침에 맞춘 재실험 절차다. 실제 재실험은 아직 수행하지 않았다.

1. Azure Portal에서 기존에 승인된 `Speech Services` 리소스가 `Free F0`인지 확인한다. 지역은 리소스에 설정된 값을 사용한다. 신규 계정·리소스가 학생 개인 카드나 결제수단 등록을 요구하면 진행하지 않는다.
2. `Keys and Endpoint`의 키와 지역을 `.env.local`의 `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`에 넣는다. 키는 문서나 Git에 올리지 않는다.
3. `ko-KR-InJoonNeural`, 속도 -5%, 기본 음높이로 고정 문장 7개를 합성하고 전체 오디오 수신 시간과 실패율을 새 결과 폴더에 기록한다.
4. 2명 이상이 발음 정확도, 어린이 명료성, 역사 캐릭터 적합성, 자연스러움을 독립 평가한다.
5. 추가 비교가 필요하고 결제수단 등록 없이 무료 API를 사용할 수 있으면 ElevenLabs의 API key와 허용된 기본 음성 `Bill`의 `voice_id`를 `.env.local`에 넣어 같은 문장을 비교한다. 무료 계정의 Voice Library API 제한은 실제 계정에서 확인한다.
6. Typecast는 후속 대안 검토가 필요하고 무료 범위에서 사용할 수 있을 때만 API key와 선택한 캐릭터의 `voice_id`를 넣고 `ssfm-v30`의 Smart Emotion으로 같은 문장을 비교한다.

## 실행 방법

1. 사용할 공급자의 값만 `.env.local`에 넣는다. 변수 이름은 [`.env.example`](../.env.example)을 따른다.
2. 아래 중 하나를 실행한다. 스크립트가 `.env.local`을 자동으로 읽는다. 키를 명령 인자나 Git에 넣지 않는다.

```powershell
npm run tts:evaluate -- --provider=azure
npm run tts:evaluate -- --provider=elevenlabs
npm run tts:evaluate -- --provider=typecast --voice=primary
npm run tts:evaluate -- --provider=typecast --voice=alt
```

Typecast 음성을 추가할 때는 첫 음성을 `TYPECAST_VOICE_ID`, 추가 음성을 `TYPECAST_VOICE_ID_ALT`에 넣는다. `--voice=alt`처럼 지정한 이름은 환경 변수 접미사와 결과 하위 폴더 이름으로 사용된다. 예를 들어 `--voice=calm-king`은 `TYPECAST_VOICE_ID_CALM_KING`을 읽고 `typecast/calm-king/`에 저장한다.

한 문장만 재시험하려면 다음처럼 실행한다.

```powershell
npm run tts:evaluate -- --provider=azure --case=historical-terms
```

결과 음성과 `results.json`은 기본적으로 `evals/sejong/w01-05-results/` 아래 공급자별 폴더에 생성되며 Git에는 포함되지 않는다. 같은 경로를 다시 실행하면 기존 결과를 덮어쓰므로 재실험에는 `--out=evals/sejong/w01-05-results/azure/2026-10-06-rerun`처럼 새 경로를 지정해 작성자의 원래 음성과 기록을 보존한다. 2026-10-06 수정 이후의 `apiLatencyMs`는 요청 시작부터 전체 오디오 본문 수신 완료까지이며 파일 저장 시간은 제외한다. 과거 `results.json`의 설명 문자열이 같더라도 기존 코드의 측정값은 본문 수신 시간을 포함하지 않는다. “듣기 요청부터 소리 시작까지”는 재생 UI의 듣기 요청 시점부터 `playing` 이벤트까지 별도로 측정해야 한다. `play()` 직전부터 `playing`까지의 구간만 측정하면 서버 요청·합성·다운로드 시간을 제외하므로 이슈의 전체 재생 지연을 대신할 수 없다.

API 키와 네트워크 없이 지연 본문 회귀 시험을 실행할 수 있다.

```bash
node --test tests/tts-evaluation.test.mjs
```

이 시험은 실제 평가 CLI를 하위 프로세스로 실행하고 모든 `fetch`를 모의 응답으로 대체한다. 응답의 마지막 바이트를 200ms 뒤에 보내 Azure·ElevenLabs·Typecast의 기록된 시간이 그 지연을 포함하고 전체 바이트가 저장되는지 확인한다. `.env.local`은 읽지 않으며 합성용 모의 키만 사용한다. 실제 공급자의 지연이나 음성 품질을 측정하는 시험은 아니다.

## 사람 청취 평가표

각 항목을 1점(부적합)~5점(매우 적합)으로 평가한다. 평가자 2명 이상이 서로의 점수를 보기 전에 독립적으로 듣는다.

| 항목 | 판정 질문 | 가중치 |
|---|---|---:|
| 발음 정확도 | 훈민정음·집현전·측우기·앙부일구·자격루와 숫자가 정확한가? | 30% |
| 어린이 명료성 | 초등 3~6학년이 한 번에 알아들을 속도와 발음인가? | 25% |
| 역사 캐릭터 적합성 | 차분함·따뜻함·단호함이 있고 과장된 사극 연기가 아닌가? | 20% |
| 자연스러움 | 문장 연결, 쉼, 억양이 기계적으로 들리지 않는가? | 15% |
| API 응답 시간 | 7개 문장의 중앙값이 3초 안쪽인가? | 10% |

총점은 `발음×0.30 + 명료성×0.25 + 적합성×0.20 + 자연스러움×0.15 + 속도점수×0.10`으로 계산한다. 한 역사 용어라도 반복해서 잘못 읽으면 총점과 관계없이 보류한다.

## 완료 판정

[이슈 #11](https://github.com/knu-history-ai/sejong-talk/issues/11)의 완료 기준은 다음과 같다.

- 같은 문장으로 후보 2개 이상 비교
- 역사 용어 발음 오류 기록
- 후보별 **듣기 요청부터 소리 시작까지 재생 지연을 3회 측정**
- 추천 후보 1개와 예비 후보 1개 선정
- 결과표와 음성 샘플 첨부

7개 서로 다른 문장의 API 호출 기록은 같은 조건의 재생 지연 3회 측정을 대신하지 않는다. 이 문서에는 작성자의 비교 결과표와 초기 음성 생성 기록이 있으나, 역사 용어별 오류 기록·후보별 실제 재생 지연 3회·이슈의 음성 샘플 첨부는 확인되지 않았다. 수정된 타이머의 실제 API 재측정과 2명 이상의 독립 청취 점수도 남아 있다. 현재 서비스 공급자 선택과 오프라인 본문 수신 시험 통과를 이슈 전체 완료로 기록하지 않는다.

실제 서비스 적용 단계에서는 승인된 `answerId`의 서버 보관 텍스트만 합성하고, 클라이언트가 보낸 임의 텍스트를 합성하지 않는다. 동일 답변 재청취는 캐시된 오디오를 재사용하며, 새 질문·중지·초기화 뒤 늦게 도착한 음성이 자동 재생되지 않게 한다.

## 현재 서비스 선택

- 선택: **Azure Speech F0, `ko-KR-InJoonNeural`, 속도 -5%, 기본 음높이**.
- 후속 대안 후보: **Typecast**. 현재 공급자나 새로운 청취 평가로 확정된 예비 음성은 아니다.
- 적용 방침: 승인된 답변의 서버 합성 경로를 사용하고, 이후 공급자 통일·교체는 호출자 규격을 유지하며 처리한다. 학생 개인 카드·결제수단 등록과 유료 사용 없이 무료 범위에서 진행한다.
- 미확인: 수정된 타이머로 실제 API를 호출한 중앙값, 현재 설정의 독립 청취 점수. 이 수정에서 새로운 실측 결과를 만들거나 원래 음성·결과 파일을 갱신하지 않았다.
