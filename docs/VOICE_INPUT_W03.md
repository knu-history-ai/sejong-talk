# W03-04: 세션 기반 STT 연결과 원음 삭제

W02-04(#24)의 녹음·인식문 확인·수동 전송을 서비스 세션에 연결했다. 대화 화면 연결은 W03-11(#46) 위에 쌓은 별도 브랜치에서 진행한다.

## 바뀐 점

| 항목 | W02-04 (#24) | W03-04 |
| --- | --- | --- |
| `POST /api/transcriptions` | 세션 없음, development 전용 | 세션 쿠키·같은 출처 필수, production에서도 동작 |
| 중복 요청 | 프로세스 전체에서 requestId 공유 | 세션별 requestId. 같은 ID+같은 음성은 1회 호출, 다른 음성은 409 |
| 취소 | 브라우저 abort만 | 브라우저 abort와 세션 초기화·만료가 공급자 호출을 중단. 늦은 결과는 버리고 401 |
| 원음 | 저장하지 않음(문서상) | 아래 "원음 처리"를 코드와 시험으로 고정 |
| 오류 코드 | `message`만 사용 | 클라이언트가 `code`(`SESSION_EXPIRED` 등)를 받아 화면에 전달 |
| `/api/dev/stt-compare` | development 전용 | 변경 없음 (`handleStt`) |

## 원음 처리

- 서버는 요청 메모리에서만 음성을 다룬다. 디스크·로그·DB·캐시에 쓰지 않는다.
- 중복 방지용 기록에는 음성의 SHA-256 해시와 최종 글 응답만 남긴다. 응답 완료 후 60초가 지나면 후속 요청 없이 자동 삭제한다. 처리 중인 요청은 만료시키지 않아 같은 requestId의 중복 호출을 막는다. 세션이 끝나면 기록을 즉시 비우고 삭제 타이머도 취소한다.
- 공급자 호출이 끝나면 서버가 가진 음성 참조를 끊는다(`audio = undefined`). JavaScript 메모리 해제 시점은 런타임이 정한다.
- 응답에는 인식문만 있고 음성·공급자 원문 오류는 없다.
- 브라우저는 녹음 조각을 녹음 종료 직후 비우고, 화면에는 바이트 수만 남긴다(W02-04와 같음).
- 공급자 측 보관은 Azure Speech Short Audio REST의 기본 동작에 따른다. 이 저장소에서 별도 로깅을 켜지 않는다.

`tests/stt-session-http.test.mjs`가 위 항목(세션 필수, 출처, 형식 오류 코드, 세션별 중복 방지, 세션 초기화 시 중단과 늦은 결과 폐기, 클라이언트 취소, 공급자 오류 비노출, 파일 쓰기·로그 없음, 기록에 음성 없음)을 검사한다. Fake timer 회귀 시험으로 후속 요청 없는 자동 삭제, TTL 경계의 진행 중 중복 방지, 세션 초기화·만료 시 타이머 취소도 확인한다.

## 실행에 필요한 설정

`.env.local`:

```sh
STT_PROVIDER=azure
AZURE_SPEECH_KEY=...
AZURE_SPEECH_REGION=koreacentral
# W03-02 사용량 정책: azure:stt를 허용해야 호출된다. 없으면 503 "음성 인식 사용량 정책을 확인해 주세요."
USAGE_PROVIDER_PLANS={"azure:stt":{"mode":"free","maxCostMicros":0},"azure:tts":{"mode":"free","maxCostMicros":0}}
```

- `/voice-input-test`는 열릴 때 시험용 세션을 만든다.
- 휴대폰(Cloudflare 터널) 시험은 `APP_ORIGIN=https://<터널 주소>`를 넣고 개발 서버를 다시 시작해야 세션이 만들어진다.

## 대화 화면 연결 (`codex/w03-04-chat-voice`, #46 위)

- 입력창의 "말로 질문" 버튼이 `ChatVoiceButton`으로 바뀐다. 녹음 → 인식 → 인식문을 입력창에 넣고 포커스. **자동 전송하지 않는다.**
- 입력창에 글이 있으면 바꿀지 먼저 묻는다. 녹음·인식 중에는 입력창과 전송 버튼을 잠근다.
- 답변 대기·새 대화 시작·세션 만료 시 진행 중인 녹음·인식을 취소한다. 서버가 `SESSION_EXPIRED`를 주면 대화 화면의 만료 처리로 넘긴다.
- `?sample=1` 예시 대화에는 세션이 없어 음성 버튼 대신 안내를 보여 준다.
