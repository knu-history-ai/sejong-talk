# 세종 1인칭 답변 검증 — PR #73

말하는 주체는 세종대왕이며, 어린이에게 `~단다/~구나/~지`로 직접 설명한다. 문장마다 `나는`을 요구하지 않으며, 승인된 사실의 내용과 출처는 유지한다.

승인 사실의 행위 주체가 세종이면 자신의 행적으로 설명한다. 어미만 바꾼 `세종이 했단다`는 1인칭 설명이 아니다. 다른 인물·기관의 활동은 그 주체를 유지하고, `세종 때`의 사건은 `내가 다스리던 때`처럼 설명한다. 자료에 없는 직접 참여·단독 발명·명령·감정·기억을 더하거나, 불분명한 주체를 세종으로 단정하지 않는다.

예를 들어 승인된 집현전 카드의 설명은 `내가 다스리던 때, 집현전은 학문을 연구하고 인재를 기르는 데 중요한 역할을 했단다.`로 표현할 수 있다. 이를 `내가 혼자 모든 연구를 했단다.`로 바꾸면 안 된다. 이 규칙은 생성 프롬프트에 적용하며, 행위 주체의 의미상 보존 여부는 실제 모델 평가로 확인해야 한다.

## 검사 범위

- 최신 리뷰의 22개 명시 사례와 기존 정상·차단 사례를 `tests/fixtures/sejong-persona-review.json`에 함께 고정한다. `tests/ai-backend.test.mjs`에서 따옴표 4종, 줄바꿈, 중첩 인용, 띄어쓰기와 문장부호 변형을 추가한다.
- 짝이 맞는 인용 구간 중 질문·자료 출처나 표현·이름 설명이 드러나는 구간만 검사에서 제외한다. 따옴표를 제거한 본문 전체를 예외로 취급하지 않는다. 인용은 기존 답변 길이 제한 400자 안에서 처리한다.
- 자기소개와 동명 친구 예외는 해당 이름 위치에만 적용한다. 서식 정리는 검사할 문자열에만 적용하며 허용한 답변을 재작성하지 않는다.
- `grounded`의 유효 사실 ID와 출처 조건은 계속 필요하다. 정상 말투라는 이유로 근거 없는 답변을 승인하지 않는다.
- 이 검사는 명시적인 세종 자기 지칭을 대상으로 한다. 대명사만 쓴 문장, 한자·영문 별칭, 모든 문장의 의미나 어미까지 판별하는 완전한 의미 검사는 아니다. #74·#75의 전체 구현은 별도다.

## 모델 평가

고정 질문 실행기는 생성 후보와 검증 후 공개 답변, 본문 유지 여부를 함께 기록한다. 실제 모델 실행과 `--mock`을 구분하고, 1인칭 유지·오차단 항목은 사람이 확인하기 전까지 null이다. 연결 실패를 모델 말투 실패율에 포함하지 않는다.
