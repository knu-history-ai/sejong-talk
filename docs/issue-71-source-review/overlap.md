## 기준 고정 전 처리

민준이 실제 개발·모델 답변 열람 이력을 확인해 사건 묶음별 개발용/최종 평가용 여부를 정한다. 최종 후보로 실제 모델 답변을 보거나 프롬프트를 조정했다면 해당 사건 묶음을 개발용으로 옮긴다는 원래 안내를 적용한다. 해결되지 않은 독립성 쟁점은 남겨 둔 채 최종 평가본으로 고정하지 않는다.

시연님은 관련 사건을 더 크게 묶어야 한다고 판단한 경우 이유를 남길 수 있다. 비공개 개발 이력 확인과 최종 분할 결정까지 시연님 개인 업무로 넘기지는 않는다. 제외가 필요해 분량·유형 비율이 달라지면 담당자가 결과를 보기 전에 다시 정한다.
