작성·대조: Codex(AI), 2026-10-15. **시연 1차 검수 완료(2026-10-15) / 검수 의견 반영·최종 정답 확정 대기**. [작업 개요](README.md) · [53문항 비교표](questions.md)

각 기사에서 **공식 국역과 우리 발췌가 같은지**, **질문이 묻는 사건의 날짜를 정답이 맞게 적었는지** 확인해 주세요. 아래의 ‘직접 확인할 점’을 따라 읽으면 됩니다.

1. [우리 발췌·질문](../../evals/sejong/date-review-20261015/model-input/모델입력_사료와질문.md)에서 해당 T번호를 찾고, 공식 원문의 국역과 비교하세요. 문장을 빼면서 인물·사건·날짜의 뜻이 달라지지 않았는지 봅니다.
2. [문항별 정답표](questions.md)에서 같은 T번호의 질문과 정답을 확인하세요. ‘이달’이면 몇 년 몇 월인지, ‘이날’이면 며칠인지, 본문에 없는 날짜를 정답이 덧붙이지 않았는지 봅니다. 이 문서의 날짜는 모두 음력입니다.
3. 확인 / 수정 필요 / 판단 보류 중 하나를 적으세요. 이해하기 어렵거나 날짜를 결정하기 어려우면 보류하고 이유를 적으면 됩니다. 다른 날짜의 기사를 새로 찾아 증명하거나 한문을 번역할 필요는 없습니다.

표의 한문은 AI가 추가로 비교한 참고 자료입니다. 시연님이 한문이나 옛 책을 찍은 원본 이미지를 직접 읽어야 한다는 뜻은 아닙니다. `/`는 서로 떨어진 짧은 구절을 구분한 표시입니다.

모든 기사의 권수·재위년·서기년·월·일이 입력 자료와 일치했다. 주석 번호와 HTML 링크 경계 공백을 제외하고, `[…]` 사이에 남긴 모든 국역 구간이 원문에 같은 순서로 존재했다. 이 기계 점검과 날짜·생략 문맥의 AI 판단은 서로 구분한다.

## 생략 표시의 공통 보완 제안

현재 `[…]`로 나눈 내부 구간은 모두 원문에 같은 순서로 존재한다. 다만 T03·T04·T09·T11·T12·T13은 원문 앞부분도 덜어낸 발췌이며, 발췌 처음에 생략 표시가 없다. T01·T05·T06·T08 등도 첫 문장 뒤의 긴 설명을 싣지 않았지만 끝에 별도 표시가 없다. 이것만으로 날짜 정답이 틀렸다고 판정하지는 않는다.

민준 확인 후 모델 입력 문서 서두에 다음 편집 원칙을 추가하는 방안을 제안한다.

> 각 본문은 기사 일부의 발췌이며, 발췌 범위 밖의 앞뒤 문단은 싣지 않았습니다. `[…]`는 발췌 내부의 생략 위치를 표시합니다.

T09는 발췌 앞에 별도 편집자 안내로 `아래 계량은 변계량을 가리킵니다.`를 두거나, 원문의 변계량 소개 부분까지 포함하는 방안을 제안한다. 인용문 자체에 원문에 없는 성을 끼워 넣지는 않는다. 수정하면 세 모델 입력 표현과 정답표 인용 위치·해시를 함께 갱신해야 한다. 이번 사전 검수에서는 원본을 수정하지 않았다.
