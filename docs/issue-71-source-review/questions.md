# 53문항 질문·정답·판정 비교표

작성·대조: Codex(AI), 2026-10-15. **시연 1차 검수 완료: 53/53문항(2026-10-15). T16-Q01 의견 해결·최종 확정 대기**. [작업 개요](README.md) · [20기사 원문 비교](articles.md)

질문 칸은 공통 지시를 뺀 원문 질문이다. 모든 문항에는 연·월과 확인 가능한 일자 및 근거를 답하라는 공통 지시가 붙는다. 정답 칸은 기존 gold의 초안을 옮겼으며 새 확정 정답이 아니다. 달력은 모두 음력이다.

53개 질문에 58개 대상 판정이 있다. 여러 사건 5문항은 두 대상이 모두 맞아야 날짜 1점이다. 날짜와 근거는 각각 0/1점이며, 연도 누락은 허용하지 않는다. 사람 검수자는 **각 행**을 확인 / 수정 필요 / 판단 보류로 바꾸고, 수정·보류는 이유와 원문 위치를 남긴다.
