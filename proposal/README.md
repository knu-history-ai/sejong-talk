# 기획·요구사항 문서

팀이 승인한 기획과 요구사항을 코드와 함께 확인하는 폴더입니다. 현재는 보관 위치만 준비했으며 실제 기획서 본문은 아직 옮기지 않았습니다.

| 문서 | 추가할 위치 | 용도 |
|---|---|---|
| 서비스 기획서 | `SERVICE_PLAN.md` | 대상 사용자, 문제, 핵심 경험, MVP 범위 |
| PRD | `PRD.md` | 기능 요구사항과 완료 조건 |
| 수행계획서 | `PROJECT_PLAN.pdf` | 학교 제출용 최종본을 보관할 필요가 있을 때 추가 |

- 문서별 최신본 하나를 유지하고 이전 버전은 Git 이력으로 확인합니다. 같은 기획서의 MD·DOCX·PDF를 모두 쌓지 않습니다.
- 개발 구조·API 연결 규칙은 `docs/`, 일정·회의록·담당 작업 현황은 Notion과 GitHub 이슈에서 관리합니다.
- Notion 등에서 내용을 변경한 경우 검토 후 반영하며 자동 동기화된 것으로 취급하지 않습니다.
- 이 저장소는 공개 저장소입니다. 팀 공유가 가능하고 공개해도 되는 내용만 넣습니다. 개인 연락처·서명·설문·메일 원문은 포함하지 않습니다.
- 운영 폴더의 문서를 통째로 복사하지 않고, 승인된 최신본과 공개 범위를 확인해 추가합니다.
